Set MAPTILER_API_KEY in the app's environment variables (Configuration -> Env)
or the map tiles will not load.


Optional keys you can also set for analytics:
- GLITCHTIP_KEY
- UMAMI_URL
- UMAMI_ID
- UMAMI_RECORDER_URL
- MIXPANEL_TOKEN
- MIXPANEL_SESSION_RECORDING_PERCENT

Datasets go in /app/data/datasets/<dataset-id>/ (use the File Manager), then
restart the app and visit the site to see the installed datasets, click on one
to view the map.
